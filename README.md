# 😇 天使と悪魔 😈

ガイスターをモチーフにした、スマホ向け2人対戦Webゲームです。

- 自分の **良いおばけ → 天使😇**、**悪いおばけ → 悪魔😈**
- 相手のおばけはすべて **妖精🧚** に見えます（種類は分かりません）
- それ以外のルールはガイスターと同一です

サーバーを持たない P2P 設計で、**運用費は0円**です。

## 遊び方

1. どちらかが「部屋を作る」を押し、出てきた部屋コード（または招待リンク）を相手に伝える
2. もう一方がコードを入力して「参加する」
3. それぞれ自陣に天使4体・悪魔4体を配置して確定
4. 交互に駒を1マス動かして対戦

勝ち方（ガイスターと同一）：

- 相手の天使を4体すべて捕獲する
- 自分の悪魔を4体すべて相手に捕獲させる
- 自分の天使1体を、相手側の角の脱出マスから脱出させる

※ 相手の悪魔を4体捕獲してしまうと負けです。1人用の CPU 練習モードもあります。

## ローカルで動かす

ビルド不要の静的サイトです。HTTPS か localhost で開いてください（暗号APIのため）。

```bash
python3 -m http.server 8765
# → http://localhost:8765 をスマホ/ブラウザで開く
```

## テスト

```bash
node --test tests/game.test.js
```

## 技術とコスト

- ホスティング：GitHub Pages（公開リポジトリ、無料）
- 対戦通信：WebRTC P2P（DTLS暗号化）。接続仲介のみ PeerServer Cloud の無料枠＋ Google STUN を使用。直接接続できない回線環境では無料の公開 TURN が暗号化データを中継
- ホストは待機ルームに入室したまま相手を待ち、タブを再読み込みしても同じ部屋で待機が復旧する
- 不正対策：配置の SHA-256 コミットメント方式（詳細は `docs/ARCHITECTURE.md`）

**運用費：¥0/月**（サーバーを持たないため課金経路がありません）

## 開発（テストとデプロイ）

- `npm test` — ルール／プロトコル／接続／演出／UI の全テスト（Node 標準テストランナー＋jsdom）
- `bash scripts/check.sh` — デプロイ前チェック（構文・全テスト・プッシュ制約）。これが通らないものはデプロイしない
- `bash scripts/deploy.sh "コミットメッセージ"` — チェック合格後に限り GitHub へ一括プッシュし、公開を確認する
